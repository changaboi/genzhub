StudentHub

Every campus event, seat and student record.

A semester project in PHP and MySQL: students register for events as tickets, admins manage students and events, and every important action lands in an audit log.

Run it locallyTake the tour

What it does

Secure accounts

Hashed passwords, CSRF protection, session timeout, login lock-out and hashed remember-me tokens.

Student management

Search, filter, sort, paginate, export to CSV and archive instead of deleting.

Events with posters

Validated, renamed uploads, categories, open or closed filters and an audit trail for every change.

JSON API and live editing

Fetch-based CRUD with proper status codes, debounced search and a built-in API inspector.

Admin dashboard

Live counts from a stored procedure, registrations by month, course split and recent activity.

Tested

189 automated checks across forms, database, sessions, uploads, API and navigation.

Run it

This page is static. The application itself needs PHP and MySQL, so it runs on XAMPP locally or on any PHP host.

1. Copy the project to  C:\xampp\htdocs\studenthub
2. Start Apache and MySQL in XAMPP
3. phpMyAdmin → Import → database/studenthub.sql
4. Open http://localhost/studenthub/
